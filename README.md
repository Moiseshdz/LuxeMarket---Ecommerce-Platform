# LuxeMarket — Ecommerce Frontend

Proyecto de comercio electrónico desarrollado como demostración de **desarrollo web frontend** con HTML, CSS y JavaScript.

El objetivo del proyecto es mostrar una experiencia de compra moderna, responsiva y completamente ejecutable en navegador, incluyendo catálogo, búsqueda, filtros y carrito de compras.

## Tecnologías

- HTML5
- CSS3
- JavaScript (Vanilla JS)
- LocalStorage
- Diseño responsivo

## Funcionalidades

- Catálogo dinámico de productos
- Búsqueda en tiempo real
- Filtros por categoría
- Carrito de compras interactivo
- Cálculo automático de totales
- Actualización y eliminación de productos del carrito
- Persistencia local del carrito
- Diseño adaptable a escritorio, tablet y móvil

## Ejecutar localmente

No requiere instalación de dependencias.

```bash
git clone https://github.com/Moiseshdz/LuxeMarket---Ecommerce-Platform.git
cd LuxeMarket---Ecommerce-Platform
```

Después abre `index.html` en tu navegador o utiliza un servidor local como Live Server.
